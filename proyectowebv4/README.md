# Mi Web Estática

Este proyecto es una página web estática que incluye HTML, CSS y JavaScript. A continuación se detallan los archivos y su propósito:

## Estructura del Proyecto

```
mi-web-estatica
├── css
│   └── styles.css        # Estilos CSS para la página web
├── js
│   └── scripts.js        # Código JavaScript para interactividad
├── images
│   └── logo.png          # Logotipo de la página web
├── index.html            # Página principal de la web
└── README.md             # Documentación del proyecto
```

## Instrucciones de Uso

1. **Clonar el Repositorio**: 
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   ```

2. **Abrir el Proyecto**: Navega a la carpeta del proyecto.
   ```bash
   cd mi-web-estatica
   ```

3. **Abrir el Archivo HTML**: Abre `index.html` en un navegador web para ver la página en acción.

## Personalización

- Puedes modificar `css/styles.css` para cambiar la apariencia de la página.
- Agrega o modifica el código en `js/scripts.js` para añadir nuevas funcionalidades.
- Cambia `images/logo.png` si deseas utilizar un logotipo diferente.
